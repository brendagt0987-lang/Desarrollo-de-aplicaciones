# App Parcial 🎬
**Flutter · Firebase**

Aplicación de autenticación y videos verticales.  
**Autora:** Brenda Isabel Gaviria Torres

## Funcionalidades
- Registro e inicio de sesión.
- Google y Facebook.
- Rutas protegidas.
- Feed de videos estilo TikTok.
- Cierre de sesión.
